Motivation
The Problem Nepal's elderly population is left behind as youth migrate abroad. No affordable, Nepali-language AI companion exists for home-based care.
  • Critical shortage of home-care resources as youth migrate abroad for work and study.
  • Existing digital health tools are English-only, cloud-dependent, focused on hospital booking — not ongoing home care.
  • Elderly patients miss medicines; emotional states go unmonitored; remote guardians rely on daily phone calls.
  • Inconsistent internet makes cloud services unreliable in rural Nepal.
Introduction
  • Goal: Build a privacy-first, local-AI healthcare companion for elderly Nepali speakers at home.
  • What we built: Raspberry Pi edge device running Whisper STT, Gemma LLM, and Piper TTS — paired with a mobile app and web dashboard.
  • Team: Team Git Force — four students at Sunway College Kathmandu with shared expertise in AI, IoT, and human-centred design.
  • Scope: Patient voice interaction, medicine reminders, mood tracking, caregiver coordination — all on a single home device.

Challenges & Solutions
  • Noisy environments: Audio preprocessing, confidence scoring, and repeat-confirmation prompts.
  • Raspberry Pi failures: Watchdog scripts and automatic service restarts.
  • Dashboard sync lag: Event-driven backend architecture with clear ownership.
  • Team coordination: Weekly sprint planning and shared API contracts across 4 parallel work streams.

Voice Input — User speaks naturally in Nepali or English

FastAPI Orchestration — Routes request to local LLM service

Gemma LLM + RAG — Determines intent: reply / medicine / mood / report
5
Piper TTS — Response synthesised to natural Nepali speech output
6
Dashboard Sync — Care events persisted to SQLite (local) + MongoDB (cloud)

Conclusion
  • Care+ validates that a culturally relevant AI health companion can be built within an academic timeframe.
  • Local AI processing eliminates cloud dependency — critical for Nepal's connectivity landscape.
  • Voice interaction proved significantly more accessible to elderly participants than text-based apps.
  • Guardian reassurance improved markedly with access to real-time medication and mood dashboards.
  • Clear pathway to pilot implementation in the Kathmandu Valley and beyond.
Future Scope
  • Clinical validation of mood and emotional trend analysis with healthcare professionals.
  • Wearable integration — heart rate, sleep, and movement monitoring.
  • Expanded multilingual support for South Asian languages.

  • Scale from households to community and institutional settings.
